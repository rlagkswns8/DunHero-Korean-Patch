# DunHero 비공식 한국어 패치

DunHero의 영어 원문을 기준으로 게임 내 텍스트를 한국어로 번역하는 비공식 패치입니다. 게임이 제공하는 폴란드어 슬롯을 한국어 슬롯으로 교체하며, 내부 호환성을 위해 로캘 코드는 `pl`로 유지됩니다.

## 패치 정보

- 패치 버전: 1.0.3
- 지원 Steam App ID: 2270210
- 지원 Steam Build ID: 24862149
- 배포 파일: `DunHero-Korean-v1.0.3.zip`
- 대상 환경: Windows 64비트 Steam판
- 번역 기준: 영어 원문 → 한국어 직접 번역

## 다운로드

GitHub 저장소의 **Releases**에서 `DunHero-Korean-v1.0.3.zip`을 받으세요. Source code 자동 생성 압축 파일이 아니라, Releases에 첨부된 동일한 이름의 ZIP 자산을 사용해야 합니다.

## 설치

1. Steam에서 DunHero를 종료합니다.
2. `DunHero-Korean-v1.0.3.zip`을 원하는 폴더에 완전히 풉니다.
3. 압축을 푼 폴더의 `DunHero-Korean-Patcher.exe`를 실행합니다.
4. `1` 또는 `install`을 선택합니다. 설치기는 Steam 라이브러리에서 게임을 자동으로 찾으며, 필요하면 설치 경로를 직접 입력할 수 있습니다.
5. 게임을 실행하고 설정의 언어에서 **한국어**를 선택합니다.

설치기는 변경 전에 지원 빌드의 원본 파일 해시를 확인하고 `DunHero_Korean_Backup` 폴더에 원본을 보관합니다. 이미 같은 버전이 설치되어 있으면 안전하게 재설치하며, 이후 새 패치 버전의 설치기가 배포될 경우 기존 설치 정보와 백업을 확인해 이전 버전을 자동 복원한 뒤 새 버전을 설치하도록 설계되어 있습니다.

## 제거 및 원본 복구

1. 게임을 종료합니다.
2. 같은 `DunHero-Korean-Patcher.exe`를 실행합니다.
3. `2`, `restore`, 또는 `uninstall`을 선택합니다.

설치 때 저장한 원본의 해시를 다시 확인한 뒤 번들, 카탈로그, 한글 폰트 런타임을 복구·제거합니다. `DunHero_Korean_Backup`은 재설치를 위해 보존됩니다. 백업 폴더를 수동으로 삭제하지 마세요.

## 번역 범위

- 아이템: 748개
- 게임플레이: 폴란드어 슬롯에 존재하는 1,065개
- 카드: 201개
- 설정: 49개
- 메타 진행: 78개
- 합계: 2,141개 비어 있지 않은 문자열
- 로컬라이제이션 테이블 밖의 장면·프리팹 및 코드 생성 UI 문구: 220개 런타임 대응 항목(테이블과 중복되는 문구 포함)

영어 테이블의 추가 항목 1개는 원문 자체가 빈 문자열이며 폴란드어 테이블에도 존재하지 않아 번역 대상에서 제외되었습니다. 장면·프리팹의 긴 도움말과 업데이트 요약문, 전투 알림, 로딩 문구 및 코드에서 동적으로 생성되는 레벨·특별 이벤트 표기도 별도 런타임 처리했습니다. 번역에는 외부 기계 번역 서비스나 자동 번역 프로그램을 사용하지 않았습니다.

v1.0.2에서는 런타임 문구를 짧은 타이머로 반복 덮어쓰던 방식을 제거했습니다. 게임이 TextMeshPro 문구를 갱신하는 호출에서 렌더링 전에 한 번 번역하며, 직렬화된 초기 문구는 해당 UI가 활성화될 때 한 번만 처리합니다. 장시간 플레이 뒤 생성되는 동적 문구와 복합 보스 포털 툴팁도 이 경로에서 처리됩니다.

v1.0.3에서는 런타임 번역을 게임의 실제 언어 선택 갱신 지점에 연결했습니다. **한국어**를 선택한 동안에만 런타임 번역이 작동하고, **English (en)**을 선택하면 추적된 문구를 즉시 영어 원문으로 복원해 메뉴·설정·크레딧이 모두 영어로 표시됩니다. 크레딧의 `Close` 오역도 `닫기`로 바로잡았습니다.

## 게임 업데이트 호환성

이 패치는 Steam Build ID 24862149 전용입니다. 게임이 업데이트되면 설치기가 변경된 파일을 감지하고 적용을 중단합니다. 이 경우 Steam에서 파일 무결성 검사를 무리하게 반복하기보다, 새 빌드를 지원하는 패치가 배포될 때까지 기다리세요. 업데이트 전에 먼저 원본 복구를 실행하는 것을 권장합니다.

## 알려진 제한 사항

- 폴란드어 슬롯을 대체하므로 패치 적용 중에는 폴란드어를 사용할 수 없습니다.
- 한국어 글꼴 출력을 위해 BepInEx 5 기반의 소형 런타임 플러그인을 사용합니다. 다른 BepInEx 모드와 함께 사용할 경우 파일 충돌 여부를 확인하세요.
- 매우 긴 문장은 일부 UI에서 줄바꿈 또는 잘림이 발생할 수 있습니다.
- Windows 64비트 Steam판 이외의 환경은 검증하지 않았습니다.
